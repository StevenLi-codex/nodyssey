# Native UI integration contract

This is the coordination contract for the complete native iOS surface. Read AGENTS.md, swiftui-working-contract.md, baseline inventory and domain bridge contracts. Minimum iOS 16. Existing Android/shared screens remain unchanged. No production mock repositories, no Compose controller, no generic Web fallback, no credentials in logs. System TabView/NavigationStack/Form/List/toolbars/sheets; Liquid Glass only for navigation/actions on supported OS. Text stays readable. Reuse existing localized strings with `String(localized:)` or `Text` resource keys; new native keys need all three locale resources in domain-owned files.

## Foundation surface (Foundation agent owns implementation)

- `NativeDestination: Identifiable, Hashable` has `id: UUID`, `route: String`, `arguments: [String: JSONValue]`; initializer `init(_ route: String, _ arguments: [String: JSONValue] = [:])`. Equality/hash use id. Route names are original NavKey minus `Key`: e.g. `PostDetail`, `Settings`, `SignIn`. Arguments match Kotlin baseline navigation and domain JSON contracts; use exact Int64 `.integer`.
- `@MainActor final class NativeAppModel: ObservableObject`: `let transport: any NativeTransport`; `@Published var session: JSONValue = .null`, `settings: JSONValue = .null`, `generation: Int = 0`; `var isSignedIn: Bool`; `func open(_ route: String, _ arguments: [String: JSONValue] = [:])`; `func openLink(_ url: String)`; `func showSignIn()`; `func resetNavigation()`; `func start() async`; `func request(_ operation: String, _ arguments: [String: JSONValue] = [:]) async throws -> JSONValue`. Owns three independent tab paths plus sheet route and session/site invalidation. Every screen gets `@EnvironmentObject var app: NativeAppModel`.
- `@MainActor final class NativeStore: ObservableObject`: init(); published `value: JSONValue = .null`, `failure: NativeFailure?`, `isLoading: Bool`; `func load(_ app: NativeAppModel, _ operation: String, _ arguments: [String: JSONValue] = [:]) async`; `func observe(_ app: NativeAppModel, _ operation: String, _ arguments: [String: JSONValue] = [:]) async`; `func invalidate()`. Use `@StateObject private var store = NativeStore()`, own `.task(id: app.generation)` and await observe so cancellation follows disappearance. Each store owns only one operation; use separate stores for concurrent resources. Null emissions clear visible content. Requests/errors are NEVER swallowed as success.
- `NativeFailureView(failure: NativeFailure, retry: (() -> Void)? = nil)` (includes auth/challenge recovery through app env); `NativeEmptyView(_ title: String)`; `NativeBusyView()`.
- Helpers `JSONValue.nativeString(_ key: String) -> String?`, `nativeInt(_ key: String) -> Int64?`, `nativeBool(_ key: String) -> Bool?`, `nativeArray(_ key: String) -> [JSONValue]`; `nativeEncoded() throws -> Data`. No fabricated required identity/default=0.
- `NativeScreen(destination: NativeDestination)` dispatches factories below, preserving environment. `NativeRootView()` uses environment app, native three-tab shell, theme/language + invalidation. Parent changes App.swift only after integration is ready.

## Domain factories and file ownership

Each factory: `static func make(destination: NativeDestination) -> AnyView?`; return nil only for routes not owned. NEVER a placeholder for an owned route. Factories are under enum names below. Each creates internal concrete SwiftUI screens from route arguments. Cross-domain navigation is ONLY `app.open(route,args)`; no compile dependencies on other domains' private screen types. Factories may use existing Rendering/Platform and Foundation APIs. Own files only within assigned directories, plus named tests/docs. Do not commit/push or modify App.swift/pbxproj/workflow/contracts owned by others.

- `NativeContentScreens`, `Native/Content/**`: PostList, Search, Notifications, PostDetail. Thread actions route to PostComposer (reply/edit args), UserSpace, ImageViewer, Stardust, ReportCompare. Own native poll UI, rich report callback integration if bridge exists. Preserve original route args and actual paging/placeholder semantics. PostDetail accepts `postId`, optional `floor`, `page`; Notification conversation opens MessageThread.
- `NativeEditorScreens`, `Native/Editing/**`: PostComposer, MessageThread. PostComposer modes from args: `postId` + `reply:true` for reply; `edit:true`, `postId`, `commentId`, `isOpeningPost`, `page` for edit; no mode for new post. Optional `quotedFloor`, `replyToAuthor`, `replyToText` preserve context. Native UITextView marked-text-safe editing, draft save/restore/flush, shared mutation single-flight. Native rich preview, attachment picker, toolbar/sticker/vote/payment support.
- `NativeAccountScreens`, `Native/Account/**`: Profile, SignIn, AccountSettings, AccountProfileFields, AccountSecurity, AccountContact, AccountBlockList, AccountPreferences, UserSpace, Follow, MyTopics, MyComments. Consume NativeTurnstile and NativeBrowser. Secrets in transient memory only. Avatar picker; stable Int64 IDs; signed-out recovery; sensitive writes confirm then read back.
- `NativeLibraryScreens`, `Native/Library/**`: Bookmarks, ReadHistory, Assets, Credit, Stardust, CommunityTools, Award, Lucky, Invite, Ruling, ReportCompare, TrackedThreads, AboutCommunity. Actual local/offline lifecycle and all spending confirmations; report native structured rendering; fetch authoritative state after mutation, no live test writes.
- `NativeSettingsScreens`, `Native/Settings/**`: Settings, ThemeSettings, DynamicColor, NotificationSettings, ProxySettings, DohSettings, NetworkCheck, AboutApp, Privacy, Changelog, Help, OpenSourceLicenses, TitleKeywords. Show genuine platform limitations; no inert switches. Settings bridge/mapping may be changed only by separate coordination. Do not silently claim unsupported route as fully implemented. All original authors/license remain.
- `NativeMediaScreens`, `Native/Media/**`: ImageHost, StickerManage, StickerGroup, StickerSources, StickerAdd, ImageViewer, Web. NativeImageGallery/NativeBrowser are existing platform implementations. Full six hosts, capability-aware galleries, secret redaction, sticker subscriptions/import/export/editing/upload; reusable `NativeStickerPicker` OPTIONAL contract coordinate with editor via doc. Cross-domain picker integration may be parent-owned.

## Tests and acceptance

Write and execute behavioral tests first for state/algorithms with consequence. No static file-string tests masquerading as runtime. Factor pure state into domain-owned Foundation Swift package where needed; use actual Mac runner conventions in NativeRenderingTests/run-mac-tests.py or NativeCore verification. Apple full build via parent CI; macOS SwiftUI signature checks do NOT prove UIKit/Kotlin linkage. Source implementation is not full acceptance. Document exact tests, remaining behavior and real tool failures. Never send real posts/messages, transfer funds, change live account security or upload media to validate. Do not claim all baseline features complete without matching every checkbox.
